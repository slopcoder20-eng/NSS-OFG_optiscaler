# Reusable test sources

These sources are supplied so users can run their own checks; no local run results are bundled.

The native host links the current production object set into an independent executable and requires the matching native NSS provider. It exercises common input contracts and is not game injection or proof of displayed cadence. Read its arguments and adapt resolution/inputs for your test. Use a developer toolchain and the final project link inputs.

submitted_rates_test.cpp checks independent real/output submission counters and multiplier transitions. Compile with the OptiScaler project directory on the include path. This does not measure monitor FPS.
